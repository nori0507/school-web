# School Website
A comprehensive, multi-page responsive website designed to showcase school information, news, and campus life. This project focuses on structured navigation, CSS layouts, and media integration.

## Technologies
- HTML
- CSS
- JavaScript
- Google Maps API

## Setup
1. Clone this repository
2. Simply open index.html in any modern web browser to view the homepage.
